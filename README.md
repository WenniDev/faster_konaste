# Faster Konaste

Little Konaste updater hook to download your game updates faster.

## Features

- Faster downloads
- Skips the files already up to date
- Download speed next to the TASK percentage

## Installation

- Download the latest release from the [releases page](../../releases/latest)
- Drop `d3d9.dll` in the `launcher\modules` folder of the game
- Start the game and update it as usual

## Tips

- Loading other DLLs too? Rename it `faster_konaste.dll` and use [d3d9_chainload](https://github.com/adamaq01/d3d9_chainload)
